Aviso

Cliente independiente construido a partir del análisis de Drama Live v13.0.3. No contiene código, assets ni contenido del producto original, y no consulta su infraestructura.

El catálogo mezcla dos tipos de canal:
· Canales sintéticos (1001–1005): segmentos MPEG-TS generados en memoria, estructuralmente válidos pero sin imagen decodificable — sirven para ejercitar el pipeline HLS del cliente, no para mostrar video.
· Canal 9001 «Canal de prueba REAL»: barras SMPTE + tono de 1 kHz codificados en H.264/AAC por este propio repo (ffmpeg). Sí se reproduce de verdad (hls.js + MSE). Contenido propio, no de terceros.

Este proyecto no redistribuye contenido de terceros. Si quieres imagen real de otra fuente, activa PASSTHROUGH=1 apuntando el catálogo a un stream del que tengas licencia, o carga una M3U propia.
